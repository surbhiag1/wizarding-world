# Screenshots

Put your project screenshots in this folder, then embed them in the main `README.md`.

Suggested file names:

- `home.png`
- `quiz.png`
- `quiz-result.png`
- `spells.png`
- `characters.png`
- `wands.png`
- `mobile.png`

Capture at 1440 × 900 (desktop) and 390 × 844 (mobile) using Chrome DevTools, and keep each file under roughly 500 KB. See the "Adding screenshots" section of the main README for the full walkthrough and a ready-to-paste Markdown block.
